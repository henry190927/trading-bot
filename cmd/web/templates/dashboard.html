Dashboard legend

Chart lines

POC200Long-term Point of Control (~8d on 1h). The price with most accumulated volume.
POC100Medium-window POC (~4d).
POC50Recent ~2-day POC. Usually closest to current price.
VAH / VALValue Area High / Low — band holding 70% of volume.
markLive BingX mark price.
entryEngine's planned entry level.
stopEngine's stop level.
TP1 / TP21R / 2R profit targets.

Meta-row chips

POC
Primary 200-bar POC price; tap to copy.
VA
VAL ↔ VAH copy buttons (the 70% volume zone edges).
HVN
Top-5 secondary chip zones (high-volume nodes) inside the 200-bar profile.
drift ↗ / ↘ / →
POC migration across 50/100/200-bar windows. (POC50 − POC200) / POC200 as %. Rising = bullish, falling = bearish, flat = chop. Bold border = stacked (POC50 > POC100 > POC200) = strong confirmation.

Diagnose chips

at VAH / at VAL
Entry within 0.3% of the value-area edge. Best mean-rev rotation setups (target = POC).
inside VA
Entry inside [VAL, VAH] but not at an edge. Chop / equilibrium; weak edge either side.
above VA / below VA
Entry outside the value area. Either acceptance (new regime forming) or extension (reversion candidate).
POC ↗ / ↘
Current regime per POC migration.
⚠ falling knife
A big bearish range-expansion bar fired in the last 3 candles. Fighting fresh downward momentum is risky for longs.
⚠ blow-off risk
Same but bullish; risky for shorts.

Score pills (tri-axis)

MR N (meta row, integer 0–6)
Mean-reversion votes: RSI extreme, BOLL band touch, fib 0.618, sweep, RSI/CVD divergence, MACD cross, range expansion. Counter-trend / fade-the-extreme setups.
MOM N (meta row, integer 0–4)
Momentum / trend votes: volume anomaly (BTC), LH-LL / HH-HL structure (ETH), NY-session bullish/bearish body (XAU), double-top / double-bottom retest (XAU). Per-symbol gating after backtest A/B — not every symbol enables every MOM vote.
total N (meta row, integer; total = MR + MOM)
Combined vote count. 3 is the engine's MIN_SCORE tradeable threshold (daemon + monitor filter on this). What the journal stores in the legacy score column.
X.X/10 (diagnose row, float 0–10)
Validator's structural fit for a specific entry at the current price. Weighted sum of ~20 factors: engine alignment (+2), sweep / fib / HVN proximity (+1.5–2), VA edge (+0.5), POC drift alignment (+0.5–0.7), minus penalties for entry chase, falling knife, counter-regime, inside-VA chop, etc.
MR x.x MOM x.x (diagnose row sub-totals)
MR sub-total = MR-tagged + shared factors capped /10. MOM sub-total = MOM-tagged + shared factors capped /10. Shared factors (engine alignment, fees, market chase) count toward both — these sub-totals are NOT additive to the combined /10.

Sizing by axis (discretionary guide)

Use the tri-axis split to read what KIND of setup is firing, then size accordingly. Engine doesn't enforce these — they're a habit-formation aid.

Meta-row 標籤

POC
主要的 200-bar POC 價；點擊複製。
VA
VAL ↔ VAH 複製按鈕（70% 成交量區間的兩端）。
HVN
200-bar 分佈內 top-5 次要籌碼區（high-volume nodes）。
drift ↗ / ↘ / →
POC 在 50/100/200-bar 三個窗中的漂移。(POC50 − POC200) / POC200 百分比。上升 = 看多、下降 = 看空、平 = 盤整。粗邊框 = 疊態（POC50 > POC100 > POC200）= 強確認。

Diagnose 標籤

at VAH / at VAL
Entry 在 value-area 邊緣 0.3% 內。最佳均值回歸型 setup（目標 = POC）。
inside VA
Entry 在 [VAL, VAH] 內但不在邊緣。盤整區 / 平衡；兩邊都沒 edge。
above VA / below VA
Entry 在 value area 之外。可能是接受期（新 regime 形成）或延伸過遠（反轉候選）。
POC ↗ / ↘
目前的 POC 漂移 regime。
⚠ falling knife
最近 3 根 K 線有一根大陰線範圍擴張。追這方向做多是接刀風險。
⚠ blow-off risk
同上但方向相反；做空的軋空風險。

Score pills（三軸)

MR N (meta row, 整數 0–6)
Mean-reversion 票：RSI 極值、BOLL 觸帶、fib 0.618、sweep、RSI/CVD 背離、MACD 交叉、range expansion。逆勢 / fade-extreme 型 setup。
MOM N (meta row, 整數 0–4)
Momentum / trend 票：vol anomaly (BTC)、LH-LL / HH-HL 結構 (ETH)、NY 盤陽陰體 (XAU)、雙頂 / 雙底回測 (XAU)。經 backtest A/B 過的 per-symbol 開關，不是每個 symbol 都啟用每個 MOM vote。
total N (meta row, 整數；total = MR + MOM)
合計票數。3 是 engine 的 MIN_SCORE 執行門檻（daemon + monitor 都以此過濾)。Journal 舊 score 欄位存的值。
X.X/10 (diagnose row, 浮點 0–10)
Validator 對「這個 entry」的結構適合度。~20 個 factor 的加權合：engine 一致 (+2)、sweep/fib/HVN 近距 (+1.5–2)、VA 邊緣 (+0.5)、POC 漂移一致 (+0.5–0.7)，減去追市、接刀、逆 regime、內盤整等扣分。
MR x.x MOM x.x (diagnose row 分軸小計)
MR 小計 = MR-tagged + 共用 factor，capped /10。MOM 小計 = MOM-tagged + 共用 factor，capped /10。共用 factor（engine 一致、fee、追市）算兩邊 — 因此小計不是總分的線性加總。

依軸調整倉位（discretionary 指南)

用三軸分佈判斷這是哪一類 setup 觸發，據此調整倉位大小。Engine 不強制執行 — 只是幫忙養成習慣。

Setup 類型解讀建議倉位
MR 高 + MOM 高例：RSI 超賣 + LH-LL 翻 HH-HL全倉
MR 高 + MOM 0純均值回歸 fade — backtest 基線場景預設倉
MR 0 + MOM 高XAU NY 盤動能、ETH 結構翻轉半倉、停損收緊
⚠ 軸線分歧警告MR 說 LONG、MOM 說 SHORT（或反之）。警告寫在 Signal.Warnings。跳過、或只做快 scalp
兩軸都 < 2confluence 弱，可能連 MIN_SCORE 都達不到跳過
